# Agentic RAG 智能体

基于 LangGraph + DeepSeek + 本地 BGE 的知识库问答智能体（Agentic RAG）。

## 项目简介

（一句话：从本地文档检索相关知识，结合大模型生成答案，支持多轮对话与工具调用。）

## 技术栈

| 层 | 选型 |
|---|---|
| 编排 | LangGraph |
| 主模型 | DeepSeek API |
| Embedding | 本地 BGE（bge-small-zh） |
| 向量库 | Chroma |
| 后端 | FastAPI |
| 前端 | Streamlit |
